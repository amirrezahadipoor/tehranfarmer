صفر گردآوری داده

خلاصهٔ یک‌خطی: این بازی هیچ داده‌ای گردآوری، ذخیره روی سرور یا ارسال نمی‌کند. همهٔ اطلاعات بازی فقط روی گوشی خود شما می‌ماند و با حذف برنامه پاک می‌شود.

۱. هیچ اطلاعاتی جمع‌آوری نمی‌شود

  • هیچ اطلاعات هویتی، شماره تلفن، ایمیل، موقعیت مکانی، مخاطبین یا شناسهٔ تبلیغاتی گرفته نمی‌شود.
  • هیچ ابزار تحلیلی، تبلیغاتی یا گزارشگر خطای ابری (SDK شخص ثالث) در برنامه وجود ندارد.
  • برنامهٔ اندروید حتی مجوز دسترسی به اینترنت (android.permission.INTERNET) را درخواست نمی‌کند.
  • همهٔ بازی ۱۰۰٪ آفلاین اجرا می‌شود؛ در حالت پرواز هم کامل کار می‌کند.

۲. چه چیزی روی گوشی شما ذخیره می‌شود؟

  • پیشرفت بازی و تنظیمات: روز بازی، محصولات، ساختمان‌ها، پیشرفت داستان و تنظیمات صدا/دسترسی‌پذیری — فقط در حافظهٔ خصوصی برنامه.
  • گزارش خطای محلی: حداکثر ۱۰ رکورد فنی بدون هیچ دادهٔ هویتی، فقط برای پشتیبانی؛ شما می‌توانید آن را از منوی «تنظیمات» ببینید، خروجی بگیرید یا پاک کنید.
  • پشتیبان دستی: اگر خودتان دکمهٔ «خروجی سِیو» را بزنید، یک فایل JSON روی دستگاه ذخیره می‌شود.

۳. حذف داده‌ها

با گزینهٔ «بازنشانی بازی» در منوی تنظیمات داخل بازی، یا با پاک‌کردن داده‌های برنامه از تنظیمات اندروید، یا با حذف کامل برنامه، همهٔ داده‌ها برای همیشه پاک می‌شوند. هیچ نسخهٔ پشتیبان ابری وجود ندارد.

۴. کودکان و خانواده

بازی بدون حساب کاربری، بدون خرید درون‌برنامه‌ای، بدون چت و بدون اینترنت است؛ بنابراین برای همهٔ گروه‌های سنی ایمن است.

۵. تغییرات این سیاست

اگر در نسخه‌های آینده تغییری در این سیاست ایجاد شود، همین صفحه با تاریخ جدید به‌روزرسانی می‌شود. نسخهٔ فعلی: ۱۰.۰.۱.

۶. تماس

پرسش یا گزارش دربارهٔ حریم خصوصی: از طریق صفحهٔ برنامه در کافه‌بازار (بخش «تماس با توسعه‌دهنده») پیام بدهید.

English summary (store review)

Mazrae Rangi (ir.mazraerangi.game) is a strictly offline single-player game.

  • Data collected: none — no personal data, no analytics, no ads, no third-party network SDKs.
  • Network permission: the Android build does not request android.permission.INTERNET.
  • On-device storage: save game, accessibility preferences and a local-only error log; all removed when the app is uninstalled or the game is reset.
  • Children: no accounts, no purchases, no chat, no connectivity.
