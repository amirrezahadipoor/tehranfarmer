# سند بالانس بازی «مزرعه رنگی» — نسخهٔ ۱۰ (سه مزرعهٔ متصل با ۱۵۴ کرت روی سرعت ثابت ۱×)

هدف طراحی: **۶۰ تا ۸۵ ساعت گیم‌پلی استاندارد** برای تکمیل کامل داستان ۶فصلی، هر ۳ مزرعه، ۵ کارگر هماهنگ و سطح ۳۰ روی سرعت ثابت و طبیعی `۱×`.

## زمان بازی و جریان طبیعی `۱×`
- سرعت بازی به صورت یکپارچه و بدون دکمهٔ تندکننده روی **`۱×` طبیعی** قفل شده است (`۱ ساعت بازی = ۸ ثانیهٔ واقعی`).
- بازیکن از روز اول به **هر ۴۰ کرت مزرعهٔ اصلی (`۸×۵`)** دسترسی کامل دارد و با پیشرفت سطح و سرمایه، دو مزرعهٔ بزرگ‌تر را آزاد می‌کند:
  - **پلهٔ ۱ املاکی (سطح ۴):** سند **«دشت شمالی» (`۹×۶ = ۵۴ کرت`)** + جادهٔ اختصاصی آسیاب بادی
  - **پلهٔ ۲ املاکی (سطح ۹):** **احیای قنات سنگی دشت شمالی** (تقویت رطوبت و نرخ رشد دشت شمالی)
  - **پلهٔ ۳ املاکی (سطح ۱۴):** سند **«باغ‌درهٔ آفتاب» (`۱۰×۶ = ۶۰ کرت`)** + جادهٔ شرقی آبشار و سروستان
  - **پلهٔ ۴ املاکی (سطح ۲۱):** **منشور یکپارچهٔ هر ۳ مزرعه (`۴۰ + ۵۴ + ۶۰ = ۱۵۴ کرت`)**
- استخدام کارگران در ۳ پلهٔ متعادل (**`۱ -> ۳ -> ۵ کارگر`**) انجام می‌شود و همهٔ کارگران بدون تداخل روی هر ۳ مزرعه، لانهٔ کاهی تخم، دامستان، استخر یکپارچه، رودخانه و کندوها کار می‌کنند.

## نتایج تاییدشدهٔ شبیه‌ساز (`STRICT=1 RUNS=20 npm run sim:balance`)
| استراتژی بازیکن | میانگین زمان تکمیل کامل (`۱×`) | وضعیت |
|---|---|---|
| بازیکن بهینه (`optimal`) | **~۵۸٫۷ ساعت** | سبز |
| بازیکن خوش‌حساب (`good`) | **~۶۱٫۱ ساعت** (`+۲۲٫۶٪` مزیت خوش‌حسابی) | سبز |
| بازیکن معمولی (`normal`) | **~۷۹٫۰ ساعت** (در بازهٔ هدف `۶۰–۸۵h`) | سبز |

## سیستم سطح (۱ تا ۳۰)
- فرمول تجربه: `xpNeed(n) = 72·n^2٫۳۳ + 80·n` — اوایل نرم، انتها پرشیب
- منابع XP: برداشت (۳+قیمت/۱۳)، فروش (مبلغ/۲۴)، کاشت ۱، ماهیگیری ۱۰، عسل ۳/عدد، بچه دام ۴۰، ساخت ساختمان ۲۵
- پاداش هر سطح: `۶۰·سطح^۱٫۶` سکه + باز شدن محتوای تازه
- محتوای قفل‌شده بر اساس سطح: بذرها (۸ محصول جدید تا سطح ۳۰)، حیوانات (خرگوش ۴ … گاو ۱۱)، دستگاه‌ها (مدل ۱ در سطح پایه، مدل ۲ +۶، مدل ۳ +۱۲)، استخر/کندو (پلکانی تا سطح ۲۴)

## محصولات (۲۴ بذر)
سود خالص هر بوته در روز به‌صورت تصاعدی: گندم ~۱۰ -> زعفران ~۴۰ -> پسته ~۱۵۰+ سکه. محصولات درخت‌مانند (fig … rose) با عمر طولانی (days ۸–۱۴) و بازکشت (regrow) — **گیاهان خارج‌فصل به خواب می‌روند و نمی‌میرند**.

## دستگاه‌ها (۷ نوع × ۳ مدل)
قیمت: `پایه × [۱، ۱۳، ۶۸]` — افکت مدل‌ها (سرعت کار، برداشت بیشتر، صرفه‌جویی بذر، کود قوی‌تر، مصرف آب/خوراک کمتر، جمع‌آوری روزانه عسل/ماهی در مدل ۳).

## سینک‌های سکه (بالانس انتهایی)
- ارتقاها: بیل/آبپاش/انبار/نیرو تا ۵ سطح تصاعدی + خاک طلایی [۲۵۰هـ، ۸۵۰هـ، ۳٫۸م]
- زمین همسایه: [۳٫۵هـ…۴۲۰هـ] × ضریب ثروت (تا ×۳٫۴ — هرچه پولدارتر، گران‌تر) — مساحت: ۱۲ <- ۱۸ <- ۲۴ <- ۳۰ <- ۴۰ قطعه (هر پله واقعی باز می‌شود)
- ۱۲ کندو: `۱۶۰۰×۲٫۰۸^n` (جمع ≈ ۸٫۵م) — ۵ استخر: `۲۵۰۰×۴٫۳^n`
- مجموع سینک نهایی ≈ ۱۸–۲۰ میلیون سکه

## قوانین تغییر فصل
فصل ۷ روز؛ گیاه بیرون‌فصل رشد نمی‌کند و نمی‌میرد (خواب). خشکسالی: ۳۶ ساعت بی‌آبی = مرگ. تقاضای فروش با هر فروش ۲٫۸٪ می‌افتد (کف ۰٫۶۶) و روزانه ۲۲٪ به ۱ برمی‌گردد.

## دستاوردها
۱۲ دستاورد × ۴–۶ پله با جایزه خودکار (سکه) — معیارهای: کاشت، برداشت، درآمد، ماهیگیری، استخر، عسل، بچه‌ها، جمع‌آوری، ساختمان، سطح، تعداد دام، روزهای بازی.

## به‌روزرسانی نسخهٔ ۷ (نهایت گسترش)
- سینک‌های جدید: **نظام حصارها** — ساخت هر گونه (۴۵۰ <- ۶٬۰۰۰) + ۲ ارتقا (۱٬۸۰۰ و ۷٬۵۰۰ سکه به ازای هر حصار) — مجموع ≈ ۷۰ هـ سکه؛ **گلخانه** (۴۲هـ + ۱۳۵هـ)؛ **سیلوی خوراک** (۳۶هـ + ۱۱۵هـ) — همه با ساختار قرارگاه‌آمدن کارگر.
- درآمد/زمان: رشد گیاهان ید ۲× سریع‌تر (روز ۹۶ ثانیه بود، حالا ۱۹۲ ثانیه ولی گلد/ساعت حفظ شده)؛ حداکثر ستامینای پایه ۲× (۲۸۰ -> …)؛ تولیدمثل دام حالا کوین نمی‌دهد ولی چرخهٔ پرندگان/پستانداران فعال است.
- اجرای شبیه‌ساز بالانس با آرام‌بخشی تمام کارگرها/ساختارها: **تکمیل (تمام پلات‌ها + ست اپ‌ها + حصارها + گلخانه + سیلو) = ۲٬۲۰۸ روز بازی ≈ ۱۱۷٫۸ ساعت واقعی در سرعت ×۱** (×۲: ~۵۹h، ×۳: ~۳۹h).
