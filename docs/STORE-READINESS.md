## ۲. کارهایی که فقط شما می‌توانید انجام دهید (پیش از انتشار)

### ۲-۱. حساب توسعه‌دهندهٔ کافه‌بازار — [کار شما]
- ایمیل، کد ملی و شمارهٔ شبا (برای تسویه) لازم است.
- ثبت‌نام در پنل توسعه‌دهندگان کافه‌بازار و پذیرش قرارداد.

### ۲-۲. کلید امضا (keystore) — [کار شما، یک‌بار برای همیشه]
اگر کلید خودتان را بسازید و به GitHub Secrets بدهید، APK خروجی **امضاشده** و آمادهٔ آپلود می‌شود.
راهنمای ساخت و افزودن Secret ها در `docs/KEYSTORE.md` است. خلاصهٔ Secret ها:

| نام Secret | مقدار |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | خروجی base64 از فایل `.jks` |
| `KEYSTORE_PASSWORD` | رمز مخزن کلید |
| `KEY_ALIAS` | نام کلید (alias) |
| `KEY_PASSWORD` | رمز کلید |

> اگر Secret ها تنظیم نشوند، گردش‌کار در اجرای غیررسمی debug و `mazrae-rangi-release-unsigned.apk` را برای آزمون می‌سازد؛ فایل unsigned برای استور مجاز نیست. تگ رسمی بدون امضا شکست می‌خورد و فقط `mazrae-rangi-release.apk` با تأیید `apksigner` قابل آپلود است.

### ۲-۳. اجرای ساخت APK از گیت‌هاب — [کار شما]
1. به تب **Actions** برو و گردش‌کار **Android APK** را انتخاب کن.
2. دکمهٔ **Run workflow** را بزن (شاخه: `main`).
3. پس از پایان، از بخش **Artifacts** این‌ها را دانلود کن:
   - `mazrae-rangi-release-apk` (فقط فایل داخلِ آن با نام `mazrae-rangi-release.apk` نصب نهایی است؛ `release-unsigned` ممنوع)
   - `mazrae-rangi-debug-apk` (فقط برای تست داخلی)
   - `mazrae-rangi-web-singlefile` (نسخهٔ وب تک‌فایل)

### ۲-۴. آزمون روی سه دستگاه واقعی — [کار شما]
حداقل یک گوشی قدیمی (اندروید ۶–۷)، یک گوشی متوسط و یک گوشی جدید. فقط همین سه چیز را ببین:
نصب بدون خطا، اجرای بازی بدون اینترنت، و لمس درست دکمه‌ها.

### ۲-۵. رده‌بندی سنی ESRA — [کار شما]
برای بازی‌های جدید در کافه‌بازار اجباری است (خوداظهاری). بازی خشونت واقعی، شرط‌بندی،
پرداخت درون‌برنامه‌ای و شبکهٔ اجتماعی ندارد؛ گزینهٔ مناسب معمولاً «+۳» یا «+۷» است.

### ۲-۶. دارایی‌های صفحهٔ فروشگاه — [کار شما]
- آیکون **۵۱۲×۵۱۲ PNG** (آیکون‌های اندروید از `npm run android:assets` ساخته می‌شوند؛ فایل بزرگ‌تر را از همان گرافیک بسازید).
- **۵ تا ۶ اسکرین‌شات** افقی با متن فارسی روی هر تصویر.
- **توضیح کوتاه** (حدود ۸۰ کاراکتر) و **توضیح بلند** با کلیدواژه‌های: بازی کشاورزی، آفلاین، داستانی، مزرعه، مدیریت مزرعه.
- لینک سیاست حریم خصوصی: فایل `docs/privacy.html` را روی GitHub Pages یا هر میزبان ثابتی منتشر کنید و لینکش را در پیشخان بگذارید.

### ۲-۷. تصمیم مجوز (License) — [کار شما]
مجوز فعلی پروژه **MIT** است؛ یعنی هر کسی می‌تواند کد و آرت را بردارد و نسخهٔ خودش را منتشر کند.
اگر بازی تجاری است، دو گزینه دارید:
1. `LICENSE` را به «All rights reserved» تغییر دهید و مخزن را خصوصی کنید.
2. یک EULA بنویسید که استفادهٔ شخصی را آزاد و بازنشر تجاری را ممنوع کند.

> **توجه:** سورس فعلی روی GitHub عمومی است. اگر می‌خواهید عمومی بماند ولی بازنشر ممنوع شود،
> همان گزینهٔ ۲ (EULA) مناسب است.

### ۲-۸. امنیت توکن — [کار شما]
توکن گیت‌هابی که در چت فرستاده شد باید بعد از پایان کار **Revoke** شود و برای دفعات بعد
یک توکن دقیق‌تر (فقط `repo` + `workflow`) ساخته شود. هیچ توکنی در فایل‌های پروژه ذخیره نشده است.

## ۳. آپلود در کافه‌بازار — [کار شما]
1. فرم اطلاعات برنامه: نام فارسی «مزرعه رنگی»، نام بستهٔ `ir.mazraerangi.game`، نسخهٔ ۱۰.۱.۱، `versionCode` ۱۰۱۱.
2. بارگذاری فایل APK امضاشده (یا AAB؛ فرمت APK برای این بازی پذیرفته است، حجم نهایی حدود ۴–۶ مگابایت و بسیار کمتر از سقف ۱۵۰ مگابایت است).
3. تکمیل توضیحات، آیکون، اسکرین‌شات‌ها، ردهٔ سنی و لینک حریم خصوصی.
4. ارسال برای بازبینی؛ زمان معمول ۱ تا ۳ روز کاری.
5. در نسخه‌های بعدی **همیشه** `versionCode` را زیاد کنید؛ ساده‌ترین راه:
   ```bash
   npm run version:bump -- patch --notes "توضیح کوتاه فارسی" --notes-en "Short English note"
   ```
   این اسکریپت `package.json`، `build.gradle` (versionName + versionCode)، `version.ts` و `CHANGELOG.md` را هم‌زمان به‌روز می‌کند.
