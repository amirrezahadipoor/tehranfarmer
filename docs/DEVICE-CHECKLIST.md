# چک‌لیست تست روی دستگاه واقعی و امولاتور اندروید (`DEVICE-CHECKLIST.md`)

این چک‌لیست وضعیت واقعی آزمون‌های خودکار روی **امولاتور سخت‌افزاری Android 14 (API 34 KVM + System WebView)** در CI (`.github/workflows/android.yml` -> `scripts/android-emulator-audit.py`) را از آزمون‌های دستیِ گوشی فیزیکی پیش از انتشار استور تفکیک می‌کند.

---

## ۱. ماتریس دستگاه‌ها و امولاتورهای هدف
1. **امولاتور سخت‌افزاری Android 14 (`API 34 x86_64 KVM` در GitHub Actions):** اجرای خودکار APK واقعی، بررسی عدم پرش سفید/سیاه اسپلش، قفل افقی، تاچ بوم Canvas، دکمهٔ سخت‌افزاری `Back`، رفتن به پس‌زمینه (`Home`) و بازگشت، و پایداری سِیو بومی پس از `am force-stop`.
2. **گوشی فیزیکی اقتصادی اندروید (`Redmi 9A / Galaxy A12` یا مشابه با تراشهٔ رده‌پایین):** تست نهایی دستی حس لمس، ویبرهٔ فیزیکی و نرخ فریم طولانی‌مدت پیش از بارگذاری در مارکت.
3. **پروفایل‌های نمایشگر مرورگر واقعی Chromium (خودکار در `e2e/`):** `640×360`، `800×360` (`20:9`)، `1024×768`، `1280×720` و `360×740 / 390×844` عمودی + بنچمارک واقعی زمان رندر بوم دوبعدی.

---

## ۲. دستورات استاندارد نصب و تست با `adb`

```bash
# ۱) تأیید خودکار ساختار باینری، نبود مجوز اینترنت و allowBackup="false" در APK
npm run android:verify

# ۲) نصب نسخهٔ دیباگ روی دستگاه یا امولاتور متصل
adb install -r artifacts/mazrae-rangi-debug.apk

# ۳) فعال‌سازی حالت پرواز (قطع کامل Wi-Fi و دادهٔ همراه) پیش از اولین اجرا
adb shell cmd connectivity airplane-mode enable

# ۴) اجرای سرد بازی
adb shell am start -W -n ir.mazraerangi.game/.MainActivity
```

## ۳. وضعیت شفاف چک‌لیست ۱۰گانه

- [x] **۱. اجرای سرد، اسپلش و نبود پرش سیاه/سفید (`P10-03` — تأیید خودکار در Android 14 KVM):** اسکن پیکسلی قاب‌های `0-coldboot`، `0-loading`، `1-start` و `3-farm` در `scripts/android-emulator-audit.py` پاس شده است.
- [x] **۲. قفل جهت افقی (`P10-05` — تأیید خودکار در Android 14 KVM):** `android:screenOrientation="sensorLandscape"` و بررسی ابعاد سطح رندر (`w_phys > h_phys`) در امولاتور تأیید شده است.
- [x] **۳. تمام‌صفحهٔ Immersive و نواحی امن (`P10-05` — تأیید در Android 14 KVM و ماتریس ۲۰:۹):** نوارهای سیستم پنهان‌اند و در پروفایل `20:9` با بریدگی دوربین هیچ دکمه‌ای هم‌پوشانی ندارد.
- [x] **۴. اجرای ۱۰۰٪ آفلاین و صفر ارسال ابری (`P9-08`, `P10-05` — تأیید خودکار):** نبود مجوز `INTERNET`، تنظیم `android:allowBackup="false"` در `AndroidManifest.xml` و اجرای کامل آفلاین در `e2e/offline-playthrough.spec.ts` و `npm run android:verify` تأیید شده است.
- [x] **۵. پایداری سِیو بومی پس از بستن ناگهانی فرآیند (`P9-07` — تأیید خودکار در Android 14 KVM):** شخم‌زدن زمین، اجرای `adb shell am force-stop ir.mazraerangi.game`، اجرای سرد مجدد و مشاهدهٔ دکمهٔ «ادامه» در `scripts/android-emulator-audit.py` به صورت زنده پاس می‌شود.
- [x] **۶. دکمهٔ سخت‌افزاری Back اندروید (`P10-04` — تأیید خودکار در Android 14 KVM):** ارسال رویداد واقعی `adb shell input keyevent 4` هنگام باز بودن مودال «انبار» صرفاً مودال را می‌بندد و برنامه را خارج نمی‌کند.
- [x] **۷. چرخهٔ حیات پس‌زمینه و بازگشت (`P7-01..P7-05` — تأیید خودکار در Android 14 KVM + تست باتری):** توقف کامل رندر/صدا در پس‌زمینه (`0` فریم مصرفی در `e2e/mobile-rig-battery.spec.ts`) و بازگشت بدون پرش پس از `KEYCODE_HOME` تأیید شده است.
- [x] **۸. اهداف لمسی `≥ 44–48px` و راست‌به‌چپ (`P2-04..P2-07` — تأیید در Chromium E2E و Android 14 KVM):** ابعاد لمسی، جبران لغزش ۱۴ پیکسلی انگشت و کلیک واقعی بوم مزرعه پاس شده‌اند. *(تست حس فیزیکی موتور ویبره نیازمند گوشی واقعی است.)*
- [x] **۹. دسترسی‌پذیری و خوانایی فارسی/انگلیسی و فونت ۱۲۰٪ (`P7-06..P7-08` — تأیید خودکار در `e2e/full-playthrough-audit.spec.ts` و `e2e/modals-audit.spec.ts`).**
- [x] **۱۰. برون‌بری و درون‌ریزی پشتیبان JSON (`P9-01..P9-03` — تأیید خودکار در `tests/platform-save.test.tsx`).**
- [ ] **۱۱. تست انسانی نهایی روی گوشی فیزیکی اقتصادی واقعی (پیش از بارگذاری نهایی استور):** نصب دستی APK امضاشده روی یک گوشی فیزیکی رده‌پایین واقعی برای ارزیابی چشمی رنگ نمایشگر، گرمای بدنه پس از ۳۰ دقیقه بازی مداوم و حس لرزش فیزیکی (`VIBRATE`).
