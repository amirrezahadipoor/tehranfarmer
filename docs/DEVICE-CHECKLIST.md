# چک‌لیست تست روی دستگاه واقعی و امولاتور اندروید (`DEVICE-CHECKLIST.md`)

این چک‌لیست آزمون **امولاتور Android 14 (API 34 x86_64 KVM + System WebView)** را از تست دستی گوشی فیزیکی جدا می‌کند. job مستقل `emulator` در `.github/workflows/android.yml` همان APK ساخته‌شده در همان commit را با `scripts/android-emulator-audit.py` اجرا می‌کند و screenshot، UI XML و logcat را در artifact ثبت می‌کند.

> **وضعیت صادقانهٔ این نسخه:** اجرای Android 14 KVM سبز شده و artifact شامل `android-14-emulator-proof` (تصاویر، UI XML و logcat) بازبینی شده است. تیک‌های وابسته به KVM بر اساس همان اجرای واقعی بسته شده‌اند؛ این نتیجه جای تست انسانی گوشی فیزیکی، بررسی notchهای متفاوت، گرما، FPS طولانی و haptics را نمی‌گیرد.

---

## ۱. ماتریس دستگاه‌ها و امولاتورهای هدف
1. **امولاتور سخت‌افزاری Android 14 (`API 34 x86_64 KVM` در GitHub Actions):** اجرای خودکار APK واقعی، بررسی عدم پرش سفید/سیاه اسپلش، قفل افقی، تاچ بوم Canvas، دکمهٔ سخت‌افزاری `Back`، رفتن به پس‌زمینه (`Home`) و بازگشت، و پایداری سِیو بومی پس از `am force-stop`.
2. **گوشی فیزیکی اقتصادی اندروید (`Redmi 9A / Galaxy A12` یا مشابه با تراشهٔ رده‌پایین):** تست نهایی دستی حس لمس، ویبرهٔ فیزیکی و نرخ فریم طولانی‌مدت پیش از بارگذاری در مارکت.
3. **پروفایل‌های نمایشگر مرورگر واقعی Chromium (خودکار در `e2e/`):** `640×360`، `800×360` (`20:9`)، `1024×768`، `1280×720` و `360×740 / 390×844` عمودی + بنچمارک واقعی زمان رندر بوم دوبعدی.

## ۲. دستورات استاندارد نصب و تست با `adb`

```bash
# ۱) تأیید خودکار ساختار باینری، نبود مجوز اینترنت و allowBackup="false" در APK
npm run android:verify

# ۲) اجرای کامل آزمون روی امولاتور API 34 بوت‌شده (خودش APK را نصب می‌کند)
npm run android:emulator

# یا فقط نصب نسخهٔ دیباگ روی دستگاه/امولاتور متصل
adb install -r artifacts/mazrae-rangi-debug.apk

# ۳) فعال‌سازی حالت پرواز (قطع کامل Wi-Fi و دادهٔ همراه) پیش از اولین اجرا
adb shell cmd connectivity airplane-mode enable

# ۴) اجرای سرد بازی
adb shell am start -W -n ir.mazraerangi.game/.MainActivity
```

## ۳. وضعیت شفاف چک‌لیست ۱۱گانه

- [x] **۱. اجرای سرد، اسپلش و نبود پرش سیاه/سفید (`P10-03` — Android 14 KVM سبز):** قاب Start، شش قاب پیاپی Farm و Resume با آستانهٔ پیکسلی سفید/سیاه سبز شدند. در اجرای نهایی Bootloader پیش از نمونه‌گیری UIAutomator تمام شد و script همان رویداد را صریحاً ثبت کرد؛ بنابراین این تیک ادعای ضبط مستقل قاب loading در همان run ندارد.
- [x] **۲. قفل جهت افقی (`P10-05` — Android 14 KVM سبز):** علاوه بر مانیفست `sensorLandscape`، ابعاد واقعی سطح `640×320` و شرط `w_phys > h_phys` تأیید شدند.
- [x] **۳. تمام‌صفحهٔ Immersive و نواحی امن (`P10-05` — ماتریس ۲۰:۹ و پروفایل KVM سبز):** در Chromium هم‌پوشانی وجود ندارد و frameهای واقعی Android بدون نوار سیستمِ پوشاننده ثبت شدند؛ notch و safe-area دستگاه‌های فیزیکی متفاوت همچنان در بند ۱۱ باقی است.
- [x] **۴. اجرای ۱۰۰٪ آفلاین و صفر ارسال ابری (`P9-08`, `P10-05` — تأیید خودکار):** نبود مجوز `INTERNET`، تنظیم `android:allowBackup="false"` در `AndroidManifest.xml` و اجرای کامل آفلاین در `e2e/offline-playthrough.spec.ts` و `npm run android:verify` تأیید شده است.
- [x] **۵. پایداری سِیو بومی پس از بستن ناگهانی فرآیند (`P9-07` — Android 14 KVM سبز):** شخم‌زدن، `am force-stop`، اجرای سرد و ظاهرشدن «ادامه» انجام شد؛ logcat نیز ذخیرهٔ native با کرت شخم‌خورده (`st:1`) را نشان می‌دهد.
- [x] **۶. دکمهٔ سخت‌افزاری Back اندروید (`P10-04` — Android 14 KVM سبز):** رویداد `adb shell input keyevent 4` فقط مودال «انبار» را بست و UI مزرعه باقی ماند.
- [x] **۷. چرخهٔ حیات پس‌زمینه و بازگشت (`P7-01..P7-05` — Chromium و Android 14 KVM سبز):** توقف رندر در Chromium و بازگشت از `KEYCODE_HOME` با قاب Resume بدون پرش سفید/سیاه در artifact Android ثبت شد.
- [x] **۸. اهداف لمسی `≥ 44–48px` و راست‌به‌چپ (`P2-04..P2-07` — تأیید در Chromium E2E):** ابعاد لمسی و جبران لغزش ۱۴ پیکسلی انگشت سبزند. تاچ Canvas روی KVM در job بالا جداگانه اثبات شد و حس ویبره به گوشی واقعی نیاز دارد.
- [x] **۹. دسترسی‌پذیری و خوانایی فارسی/انگلیسی و فونت ۱۲۰٪ (`P7-06..P7-08` — تأیید خودکار در `e2e/full-playthrough-audit.spec.ts` و `e2e/modals-audit.spec.ts`).**
- [x] **۱۰. برون‌بری و درون‌ریزی پشتیبان JSON (`P9-01..P9-03` — تأیید خودکار در `tests/platform-save.test.tsx`).**
- [ ] **۱۱. تست انسانی نهایی روی گوشی فیزیکی اقتصادی واقعی (پیش از بارگذاری نهایی استور):** نصب دستی APK امضاشده روی یک گوشی فیزیکی رده‌پایین واقعی برای ارزیابی چشمی رنگ نمایشگر، گرمای بدنه پس از ۳۰ دقیقه بازی مداوم و حس لرزش فیزیکی (`VIBRATE`).
